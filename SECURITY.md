# Security Policy

Security support may vary by project. Check the project's own SECURITY.md for its status and instructions.

## Reporting a vulnerability

Do not report suspected vulnerabilities in public issues or discussions. Use GitHub private vulnerability reporting for the affected repository when enabled. Otherwise, contact maintainers privately through GitHub and ask for a secure route. Include the affected project and version, observed impact, and reproduction steps where safe.

Please allow maintainers reasonable time to investigate and coordinate a fix before disclosure. This policy does not promise a response time or security support for every project.
