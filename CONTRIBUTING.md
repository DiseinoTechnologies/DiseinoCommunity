# Contributing

DiseinoCommunity is being established; project processes will grow over time. Contributions are welcome where a repository clearly invites them.

## Before contributing

1. Read the project's README, contribution guidance, and licence.
2. Check open issues or discussions for existing work.
3. For substantial changes, open an issue or discussion first when available.
4. Keep changes focused and explain the problem they solve.

## Submitting a change

- Describe the reason and effect of the change.
- Update documentation when usage or behavior changes.
- Follow project conventions and validation steps.
- Do not include secrets, personal data, proprietary product material, or third-party material without the rights needed to publish it.
- Be prepared for questions or revisions. Submission does not guarantee acceptance or ongoing maintenance.

For security reports, follow [SECURITY.md](SECURITY.md), not a public issue. All participants are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
