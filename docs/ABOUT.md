# About Diseino Technologies

Diseino Technologies is an independent software studio founded and operated by a solo founder. It is at an early stage and building toward a portfolio of useful software products.

The studio is product-oriented: it aims to develop software that can stand on its own and serve real needs. Its longer-term ambition is to remain deliberately small while using technology and automation thoughtfully.

## How Diseino works

Diseino takes an AI-native approach. AI is intended to contribute to research, software engineering, product development, and automation. The founder remains responsible for direction, review, and decisions. This is a development philosophy, not a claim that every activity is automated or that AI removes the need for careful engineering.

## Who Diseino aims to serve

The studio aims to create capable, affordable software for individuals, developers, creators, small organizations, and communities, including people without large-enterprise budgets.

DiseinoCommunity is the studio's public community and open-source initiative. It is being established; its project portfolio is still to come.
